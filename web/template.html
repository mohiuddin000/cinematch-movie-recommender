CineMatch

A hybrid content-based movie recommender built on the TMDB 5000 dataset – text semantics + metadata + quality prior.

Model comparison

TMDB has no user ratings, so evaluation uses proxy metrics over all movies (top-10 lists): Genre Jaccard (genre overlap with the query movie), Same director (share of recommendations by the query’s director), Coverage (share of the catalogue ever recommended) and Mean rating. The baseline already sees genres in its text, so genre overlap slightly favours it; coverage and director-match are the clearer signals.

Text-vs-metadata weight (α sweep)

Dataset overview

  1. Cleaning – merge movies and credits on id (the original title-merge created duplicate rows), parse JSON columns, fill missing text.
  2. Features – (a) TF-IDF (1–2-grams) on overview + tagline; (b) metadata tokens: genres, keywords, top-5 cast and director, each name kept as one token (so “Sam Worthington” is not split into two weak words).
  3. Hybrid similarity – sim = α·cos(text) + (1−α)·cos(metadata) with α chosen from the sweep.
  4. Quality re-rank – candidates are scaled by a Bayesian weighted-rating percentile (IMDB formula), so obscure films with a few votes do not dominate.
  5. Evaluation – offline proxy metrics against the original TF-IDF baseline (Results tab).
  6. Limitations – content-only (no collaborative signal, no cold-start users), proxy evaluation, 4,800 films, English text.
